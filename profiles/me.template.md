# Profile

Generated by `forge init` on {{.Generated}}. **Edit it.** The generated values are a
starting point taken from five questions; the fields below are what actually shape every
note the forge writes, and the defaults will be wrong for you in at least one place.

`skills/forge/SKILL.md` reads this file before synthesis and states the effect of each
field there, in a table. That is deliberate: a profile the model reads but does not act
on is worse than no profile, because it looks like personalization while producing
generic output.

## What each field does

| Field | Concrete effect on output |
|---|---|
| `primary_language` | all code examples in this language unless the topic is language-specific |
| `frameworks` | assumed available; a note may use them without introducing them |
| `infra` | worked examples target this infrastructure rather than a generic one |
| `seniority` | `junior` → define terms, one worked example per claim; `mid` → skip definitions, keep tradeoffs; `senior` → skip tradeoff basics, keep edge cases and failure modes |
| `default_depth` | 1–5; sets section count and how far a note follows a mechanism down |
| `note_language` | the prose language of the note body (code and identifiers stay English) |
| `explain_style` | orders the template sections |
| `assume_known` | these concepts are referenced, never re-explained |
| `never_assume` | these get a one-line primer inline, every time |
| `code_style` | passed verbatim into the synthesis prompt as constraints |
| `avoid` | negative constraints applied in the final pass |

## Fields worth editing by hand

`assume_known` and `never_assume` are the two that pay off fastest and that no
five-question wizard can guess. Every entry in `assume_known` deletes a paragraph you
would have skipped; every entry in `never_assume` adds the one line you would otherwise
have looked up.

`code_style` is passed through verbatim, so it can be as specific as you like —
"constructor injection, no field @Autowired, records for DTOs, Java 21" produces
different code than "idiomatic Java".
